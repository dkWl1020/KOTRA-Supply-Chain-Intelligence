# 기존 팀 통계

team_statistics.csv: 첨부 에너지·자원 조사표에서 전사한 56개 관측 행. 2023년 민간 고용 LQ와 2019–2023년 고용 변화. 원자료 재계산이 완료된 통계와 섞이지 않도록 기본 DB 적재에서 제외했습니다. 누락·비공개를 0으로 바꾸지 않았습니다.

원래 연구 자료는 inputs/에 모두 보관했습니다. 통계별 파일명과 표 위치는 CSV에 있습니다. 정부 원자료를 확보하면 수치·분모·NAICS 개정판을 대조한 뒤 data/statistics.csv로 옮길 수 있습니다. GDP 비중은 연도와 분모가 충분히 명시되지 않아 자동 전사 대상에서 제외했습니다.
