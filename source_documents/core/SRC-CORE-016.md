# AWS investment in Oregon

AWS는2012~2021년 Oregon에156억 달러 자본투자. Umatilla Electric Cooperative가 Morrow·Umatilla County의 AWS 데이터센터에 전력을 공급. 누적투자와 단일사업비를 구분

기관: Amazon
원문: https://www.aboutamazon.com/news/aws/committed-to-our-communities-the-economic-impact-of-awss-15-6-billion-investment-in-oregon

이 파일은 공개자료를 읽고 작성한 근거 요약이며 원문 전체의 복제본이 아니다.
