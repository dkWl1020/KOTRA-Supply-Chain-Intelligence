# 2024 Trout value Northwest release

2024년 Idaho 송어 판매액은 표의 Total value of fish sold 기준44,530천달러; 배포가치16,492천달러는 별도 항목. 알 제외. 본문의 sold and distributed 표현보다 표 열 정의를 우선하여 판매액으로 저장

기관: USDA NASS
원문: https://www.nass.usda.gov/Statistics_by_State/Oregon/Publications/Current_News_Release/2025/TROUT.pdf

이 파일은 공개자료를 읽고 작성한 근거 요약이며 원문 전체의 복제본이 아니다.
