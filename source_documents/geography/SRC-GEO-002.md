# TIGERweb ACS 2024 주·카운티 경계

https://tigerweb.geo.census.gov/arcgis/rest/services/Generalized_ACS2024/State_County/MapServer

2024년 1월 1일 기준 일반화 경계 서비스. States 20M은 계층 9, Counties 20M은 계층 13. GeoJSON 출력을 지원하며 EPSG:4326을 요청할 수 있음. 서비스 설명을 읽었으나 이 실행환경에서는 실제 경계 API 응답 다운로드가 차단됨.
