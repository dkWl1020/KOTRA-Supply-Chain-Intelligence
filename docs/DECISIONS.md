# 구현 결정

- 단일 담당자용 로컬 프로토타입: Python 표준 라이브러리와 SQLite 사용. 외부 패키지 설치 없이 데이터 적재·검색·분석·보고서 흐름을 실행하는 데 초점
- CSV: 초기 자료 적재와 교환용. 분석·검토·알림·보고서 등 실행 중 생성되는 기록은 DB에 저장
- 검색: 공개 근거 요약을 대상으로 SQLite 검색 사용. 별도의 유료 벡터 DB 없이 시작하며 원문을 확보하면 분할 범위를 확대
- AI: 외부 서비스 키가 있을 때 생성형 분석. 키가 없을 때의 근거 정리 결과는 생성형 AI 결과로 표시하지 않음
- 좌표와 경계: 출처가 확보된 데이터만 표시. 다운로드가 차단된 경계 자료와 기업의 실제 운송 경로를 임의 생성하지 않음
- 북부 캘리포니아: 조사 권역 ID는 유지. 포함 카운티가 확정되기 전에는 베이 9개 카운티나 주 전체를 북부 40개 카운티의 대체 통계로 사용하지 않음
- 다중 사용자·공개 서비스: 계정 인증, 역할별 접근, 별도 운영 배포는 후속 운영 범위. 관련 DB 구조는 준비하되 현재 로컬 실행을 다중 사용자 서비스로 설명하지 않음
- 모든 자료가 같은 양일 필요는 없음. 실제 근거가 확보된 자료는 자세히, 근거가 없는 관계는 빈칸으로 유지
