# 데이터 채택 기준

이 프로젝트에서 사용할 수 있는 자료의 기준은 발행 주체, 원문, 숫자의 의미를 추적할 수 있는지입니다. 기관 종류는 넓게 허용하고, 용도와 한계를 함께 저장합니다.

## 채택 범위

- 정부·공공기관: 통계, 행정자료, 인허가, 재난·규제 발표
- 대학·연구기관: 연구 데이터, 방법이 공개된 분석
- 산업협회·지역 경제기관: 산업 규모와 회원·클러스터 자료
- 기업: 자사 시설, 제품, 계약, 투자, 실적 공시와 발표
- 민간 조사기관·언론: 조사 범위나 원자료를 추적할 수 있는 통계 및 사건 보도
- 팀 자료: 제공된 연구를 보존하되 직접 대조한 원자료와 구분

기업의 자사 투자 발표는 해당 기업의 발표 내용에 대한 근거입니다. 지역 전체 시장 규모나 사업의 실제 준공을 보증하지 않습니다. 연구기관의 전망도 실적과 구분합니다.

## 수치 채택의 최소 조건

1. 누가 발표했는지와 어느 원문인지 식별 가능
2. 수치, 단위, 대상이 해석 가능
3. 기준 시점·집계 범위는 확인되는 만큼 저장
4. 출처의 표·문단·검색어를 근거 행에 기록

연도·분모·방법이 빠진 자료도 자료 목록에는 보존할 수 있습니다. 다만 같은 기간의 비교나 증감률 계산에 자동 투입하지 않습니다. 빈값, 비공개, 해당 없음과 실제 0을 구분합니다. 근사값은 근사값으로, 투자 계획은 계획으로 저장합니다.

## 기록 방식

- `sources.csv`: 기관, 원문 주소, 버전, 수집 시점, 보관 파일
- `evidence.csv`: 어떤 기록의 어떤 값을 뒷받침하는지, 원문 내 위치
- `statistics.csv`: 값과 단위, 기간, 지역·산업 범위, 실적·추정·계획 등의 종류
- `source_documents/`: 대조 메모 또는 확보한 원자료. 대조 메모는 원문 전체 사본과 다름
- `research/team_statistics.csv`: 팀 문서의 계산값을 그대로 전사한 자료. 기본 DB 적재에서 제외

## 같은 숫자의 여러 버전

원작성기관의 같은 시계열·최신 개정판을 기본으로 선택합니다. 다른 집계 범위는 덮어쓰지 않습니다. 주 전체 수치를 북부 캘리포니아 수치로 바꾸지 않고, 직접고용을 직간접 고용으로 확대하지 않습니다. 시설 투자액과 정부 보조금도 더해 하나의 총투자액으로 만들지 않습니다.

## 공급망과 위험

- 기업 간 계약과 시설 간 실제 납품을 구분
- 항만의 운영 노선과 특정 기업이 사용하는 노선을 구분
- 지역 재난 노출, 보고된 운영 차질, 분석상 가능성을 구분
- 과거 사건은 재현 사례로 저장하고 현재 경보로 발송하지 않음
- 규제 문서의 발표·시행·유예·종료를 구분하고 조건 없이 특정 세율을 기업에 적용하지 않음
- AI가 출처, 거래량, 재고, 납품지, 피해액을 새로 만들지 않도록 반환 ID와 근거를 검증

자료가 적은 분야를 숫자로 채우기 위해 추정치를 생성하지 않습니다. 대신 보완할 공급원과 연결 조건을 수집 목록에 남깁니다.
