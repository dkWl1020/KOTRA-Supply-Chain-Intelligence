# 지역과 산업 범위

과제의 7개 권역과 13개 산업을 모두 등록했다. 지역·산업 조합 91개는 첨부 엑셀의 조사 범위를 그대로 보존한다. `priority`는 과제상 우선 조사, `in_scope`는 조사 대상, `unspecified`는 원본의 미정, `excluded`는 이번 조사에서 제외한다는 뜻이다. 특정 산업의 존재 여부나 경제적 중요도를 판정하는 값이 아니다.

북부 캘리포니아(`US-CA-NORTH`)는 과제에서 사용하는 권역이다. 첨부 조사본은 40개 카운티를 가정했다고 명시하지만 확정된 카운티 목록은 제공하지 않는다. 따라서 이 파일은 40개 목록·총계·경계를 임의로 만들지 않았다. 캘리포니아 주 전체(`US-CA`)와 베이 지역 9개 카운티(`US-CA-BAY9`)는 별도 비교 범위다.

베이 9개 카운티: Alameda, Contra Costa, Marin, Napa, San Francisco, San Mateo, Santa Clara, Solano, Sonoma. `region_memberships.csv`에 구성 관계를 등록했다. 북부 전체의 통계에 베이 지역 수치를 덮어쓰면 안 된다.

## 지도 경계

경계 공급원은 U.S. Census Bureau의 TIGERweb ACS 2024 일반화 경계다. 주 경계는 계층 9, 카운티 경계는 계층 13, 출력 좌표계는 EPSG:4326이다. 이번 실행환경에서 경계 응답 다운로드가 HTTP 403으로 차단되어 `geographies.geojson`은 빈 FeatureCollection과 실제 수집 상태를 담는다. 임의 좌표나 사각형으로 대신하지 않았다.

네트워크 접근이 가능한 개발환경에서 다음 명령으로 실제 경계를 받는다.

```bash
python scripts/fetch_geographies.py
```

스크립트는 7개 주 경계와 베이 9개 카운티 경계가 모두 있어야 결과를 저장한다. 베이 전체는 9개 카운티의 GeometryCollection으로 표현하며, 내부 경계가 제거된 단일 폴리곤은 아니다. 북부 40개 카운티 경계는 생성하지 않는다. 실패 시 기존 파일은 보존하고 오류를 반환한다.

좌표가 확보되면 포인트를 지도에 표시할 수 있지만, 주 경계만으로 특정 시설의 노출·피해를 계산하지 않는다. 회사 본사 주소를 생산시설의 위치로 대입하지 않는다.

## 산업 분류

13개 산업은 프로젝트의 사용자 정의 분류다. NAICS·HS 코드와 일대일 대응하지 않는다. 포토닉스·반도체·ICT, 첨단·일반 제조, 임산업과 식품가공처럼 범위가 겹칠 수 있는 분야는 별도의 코드 대응표와 지표 정의에 따라 집계한다. 지역별 역할은 정부·산업기관 자료에서 지원되는 내용만 적었다. 역할 자료가 없는 조합은 조사 범위만 표시한다.

수치 자료의 `region_id`는 실제 발표 범위를 따른다. California statewide 수치는 `US-CA`, Bay9 수치는 `US-CA-BAY9`, 개별 카운티는 해당 FIPS 지역 ID를 사용한다.
