# KOTRA 자료·개발 패키지

미국 서북부 7개 권역·13개 산업의 공개 조사자료를 공통 ID로 연결하고, SQLite DB와 로컬 웹 프로토타입을 함께 담았습니다. 제공해 주신 조사 원본과 54개 필요 파일 목록도 포함했습니다.

## 먼저 볼 파일

1. `파일목록.csv`: 원래 54개 항목이 어느 파일·DB 테이블로 구현됐는지, 실제 데이터가 있는지 설명
2. `data/`: 바로 읽거나 코딩에 사용할 27개 CSV. 숫자·단위·기간·근거를 각각 열로 분리
3. `data/data_dictionary.csv`: 모든 열의 자료형·의미·키·참조 규칙
4. `docs/BUILD_SEQUENCE.md`: 자료 구축부터 웹·AI·보고서 연결까지의 순서
5. `검증결과.md`: 검사 결과와 실행 환경에서 검증하지 못한 범위
6. `examples/korean_air_report.html`: 저장된 공개 근거로 만든 보고서 초안 예시

## 자료 규모

- 7개 조사 권역, 13개 산업, 지역·산업 조합 91개
- 기업·기관 38개, 시설 35개, 품목·서비스 18개, 산업별 활동 36개
- 수치 관측 84개, 지표 정의 25개, 기업 관계 10개, 투자·인수 사업 3개
- 과거 사건 10개, 영향 연결 12개, 구조적 위험 20개, 규제 문서 4개, 대응 선택지 14개
- 자료 102개, 근거 연결 473개, 수집 공급원 15개
- 팀 문서의 LQ·고용 변화 56개는 `research/team_statistics.csv`에 별도 보관

수치가 모든 산업에 같은 양으로 들어 있지는 않습니다. 공개 자료에 근거한 실제 값만 본 데이터에 넣었으며, 실적·계획·추정의 종류와 집계 범위를 보존했습니다. 자료 수에는 정부·기업의 외부 자료뿐 아니라 조사 범위와 분석 방법을 설명하는 프로젝트 문서도 포함됩니다.

## 바로 실행

Python 3.11 이상과 SQLite FTS5가 필요합니다. 별도 pip 패키지는 없습니다. 압축을 푼 뒤 이 README가 있는 폴더에서 실행합니다.

```bash
python run.py init
python run.py validate
python run.py serve --port 8000
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. macOS·Linux에서 `python` 명령이 없으면 `python3`를 사용합니다. 기업·시설, 지역·산업, 수치, 사건·위험, 분석·보고서, 자료·근거, 관심 대상·알림을 탐색할 수 있습니다.

`runtime/kotra.sqlite`에는 자료와 보고서 초안 예시가 이미 들어 있습니다. `init`을 다시 실행해도 같은 ID를 중복 생성하지 않습니다. CSV 파일에서 행을 지운 것만으로 기존 운영 DB의 기록을 삭제하지 않습니다. 완전히 새로 구축하려면 기존 DB를 백업하고 `KOTRA_DB`를 새 파일 경로로 지정한 뒤 초기화합니다.

## AI 연결

`.env.example`을 `.env`로 복사하고 `OPENAI_API_KEY`와 계정에서 사용할 수 있는 `OPENAI_MODEL`을 입력합니다. 그다음 웹의 ‘설정된 AI 모델로 초안 생성’을 선택합니다. 설정 없이도 근거를 모으는 규칙 기반 미리보기를 사용할 수 있습니다. 실제 API 호출은 이 제작 과정에서 실행하지 않았습니다.

AI에는 선택 기업에 연결된 공개 기록·근거를 전달합니다. 출력의 기록 ID·근거 ID를 검증하고 분석 당시 입력을 보존합니다. 문장 의미 전체의 정확성은 담당자가 검토합니다. 보고서를 승인한 뒤 수정하면 다시 초안 상태가 됩니다.

## 수집과 갱신

```bash
python run.py collect-usgs
python scripts/fetch_geographies.py
python run.py index
```

USGS 수집기는 실제 사건 관측을 저장하지만 기업 피해를 자동 생성하지 않습니다. 15개 수집처 중 범용 자동 수집 코드가 구현된 것은 USGS이며, 나머지는 주소·방식·인증 조건과 조회 설정을 정리했습니다. 연결이 차단되면 오류를 기록하고 기존 데이터를 유지합니다. 자동 실행 예약은 별도로 설정해야 합니다.

Census 경계 다운로드는 제작 환경에서 HTTP 403이 발생했습니다. 따라서 `geographies.geojson`은 빈 상태와 사유를 담고 있으며, 제공된 스크립트로 연결 가능한 환경에서 내려받을 수 있습니다. 운송 선형도 원자료가 없어 `transport_network.geojson`에 임의 선을 넣지 않았습니다. 시설 점 4개와 사건 대표점 1개는 근거와 함께 포함했습니다. 대표점은 시설 경계나 재난 피해 영역이 아닙니다.

북부 캘리포니아의 40개 카운티 목록은 원래 자료에서 확정되지 않았습니다. 조사 권역, 베이 9개 카운티, 주 전체를 분리해 두었으며 주 전체 수치를 북부 권역 수치로 사용하지 않습니다.

## 구조

- `inputs/`: 제공된 조사 문서·표·PDF와 최신 과제·체크리스트 읽기본
- `data/`: DB 적재용 CSV
- `source_documents/`: 원문을 직접 대조한 짧은 요약, 링크, 파일 해시. 모든 원문 전문이 저장된 것은 아님
- `research/`: 원자료 재대조 전의 팀 계산값
- `db/migrations/`, `schemas/`: 테이블·제약과 데이터·AI 출력 계약
- `ingest/`, `config/`, `scripts/`: 자료 적재·외부 수집·경계 다운로드
- `api/`, `web/`: 실행 가능한 서버·화면
- `prompts/`, `risk_rules.yaml`, `report_templates/`: AI 지시문·알림 기준·보고서 형식
- `document_chunks.jsonl`, `search_index/`: 근거 요약에서 생성한 검색 자료
- `runtime/`: SQLite DB와 적재 로그
- `tests/`, `docs/`, `examples/`: 검증 코드·개발 안내·보고서 예시

## 조건부 자료와 운영 범위

`classification_mappings.csv`, `relationship_routes.csv`, `regulation_scopes.csv`는 필드·참조 구조를 갖춘 빈 파일입니다. 정확한 산업 코드 대응, 기업의 실제 운송 노선, 품목·원산지별 규제 적용 근거를 확보한 뒤 채웁니다. 자료가 없다는 이유로 거래나 규제 적용을 추정하지 않았습니다.

현재 코드는 한 담당자가 자기 컴퓨터에서 사용하는 프로토타입입니다. 직원별 로그인·권한, 인터넷 서비스 배포, 사용자 미팅과 최종 발표는 후속 작업입니다. 브라우저의 전체 클릭 흐름과 실제 외부 모델 응답은 환경 제약으로 검증하지 못했습니다. 데이터 무결성·API 처리·보고서 버전·실패 처리는 자동 검사했습니다.

## 검사 실행

```bash
python -m unittest discover -s tests -v
python run.py validate
```

숫자 0과 누락 구분, 중복 적재, 잘못된 참조·AI 근거 차단, 수집 실패, 과거 사건 알림 제외, 보고서 승인 후 수정, API 처리 등을 검사합니다. 전체 54개 항목의 수용 기준은 `docs/ACCEPTANCE.md`에 있습니다.
